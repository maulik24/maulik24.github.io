# Maulik Haria — personal site

Plain HTML and CSS with one small script (`app.js`). No install, no build step.
Made for GitHub Pages: `index.html` is at the top of this folder and every link is relative.

## Open it
Double-click `index.html`, or open it from your browser with File → Open File.

## Pages
- `index.html` — Home: experience, skill filter, tools and training
- `about.html` — About: the story, education, activities
- `projects.html` — the industry study card
- `resume.html` — résumé in HTML, plus the PDF link
- `contact.html` — email, LinkedIn, GitHub

## Things to finish
Search all files for `[PLACEHOLDER]`. Then:
- **Photo:** save it here as `photo.jpg` (or `photo.png`). It appears automatically on Home and About.
- **Résumé PDF:** save a version *without your phone number or GPA* here as `resume.pdf`, then follow the comment in `resume.html` to swap "coming soon" for the download link.
- **About text:** rewrite the draft in your own words.
- **Projects:** add the 150–250 word summary and the report, slides and chart links.
- **GitHub:** add your profile link on `contact.html`.

## Privacy
Everything in this folder becomes public. No phone number, home address, student ID, GPA or transcript.

## Publish on GitHub Pages
Upload the *contents* of this folder to a public repo (so `index.html` is at the top), then
Settings → Pages → Deploy from a branch → main / (root) → Save.
